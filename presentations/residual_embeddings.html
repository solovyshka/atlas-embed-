Риск-менеджмент Результаты OOT

Residual-эмбеддинги поверх готового риск-скора

Один принцип для отрасли и для региона: не пересчитываем дефолт, а учим поправку к frozen boost score. Сначала ОКВЭД, затем региональная модель, в конце — почему более ранние постановки не дали прироста.

Главный тезис И ОКВЭД, и регион объясняют только остаток после индивидуального скора: logit(p_final) = logit(p_boost) + α · Δ.

1. ОКВЭД — постановка

Учим отраслевую поправку к готовому boost score. Две архитектуры: flat по полному коду и hierarchical по уровням кода.

logit(p_final) = logit(p_boost) + α · Δ_OKVED

logit(p) = ln(p / (1 − p)). Добавки живут в шкале log-odds.

p_final = sigmoid(logit(p_boost) + α · Δ_OKVED)

p_boost — готовая вероятность существующего бустинга.

Δ_OKVED — поправка только из ОКВЭД.

α — сила поправки: если сигнал слаб, модель уменьшает влияние.

Безопасный старт Последний слой инициализирован нулями. До обучения Δ_OKVED = 0, то есть p_final совпадает с p_boost.

ОКВЭД — структура модели

На входе один готовый score и один основной ОКВЭД. Меняется только способ получить отраслевое представление.

ОКВЭД — обучение

Временной split

Train — прошлый период; validation — следующий; test — самый свежий. Проверяем устойчивость во времени.

OOF / frozen score

На train — OOF boost score. На validation/test — скор модели, не обучавшейся на этих таргетах.

Vocabulary только train

PAD для отсутствующего уровня, RARE для редкого, UNK для нового кода.

Loss = −mean(y·ln(p_final) + (1−y)·ln(1−p_final))

Минимизируем BCE. Early stopping выбирает эпоху по validation loss.

Gini = 2 · ROC AUC − 1

Метрика дальше — прирост Gini в п.п. к frozen boost score. +1 п.п. Gini = +0.5 п.п. AUC.

2. Региональная модель — постановка

Тот же residual-принцип, но вход — два адресных региона: регистрации и фактический. Сеть учит взаимодействие пары, а не один код.

logit(p_final) = logit(p_boost) + α · Δ_region

Формула совпадает с ОКВЭД. Меняется только источник Δ.

p_final = sigmoid(logit(p_boost) + α · Δ_region)

p_boost — тот же frozen / OOF-скор бустинга.

Δ_region — поправка из регистрации, фактического региона и флага равенства.

α — сила поправки. Последний слой нулевой: до обучения p_final = p_boost.

Безопасный старт Региональная ветка не сдвигает скор, пока не найдет устойчивый остаточный сигнал.

Общая таблица эмбеддингов на 70 регионов. Признаки — два вектора, |разность|, произведение и equal_flag. Размерность взаимодействий: 4·4 + 1 = 17.

Та же BCE, что у ОКВЭД. Early stopping по validation loss. Метрика — прирост Gini в п.п. к frozen boost score.

3. Почему не сработали более ранние эксперименты

До residual-постановки проверяли четыре подхода «в лоб». Ни один не дал устойчивого прироста к готовому boost score.

Категория прямо в CatBoost

Полные коды и регионы высококардинальны и неравномерны. Для редкого значения наблюдений недостаточно, чтобы оценить отдельный эффект.

Нейросеть без boost score

Сеть видит только отрасль или регион и не видит персональный риск, который бустинг уже извлек из дохода и платежной дисциплины.

FMM — смесь распределений

P(y) = Σ π_k · P(y | группа k). Это безусловный PD группы. Большая часть сигнала уже в boost score. Прироста не было.

Factorization machines

ŷ = w₀ + Σ wᵢxᵢ + Σ ⟨vᵢ, vⱼ⟩ xᵢxⱼ. Для редкого кода вектор v почти не оценивается. Прироста тоже не было.

Поэтому остались две residual-ветки

Все четыре подхода конкурируют с бустингом FMM отвечает: «насколько группа в среднем плохая». FM отвечает: «с какими признаками код пересекается». Residual-сеть отвечает иначе: «насколько этот ОКВЭД или эта пара регионов меняет шансы сверх уже учтенного скора».
Нужная постановка ОКВЭД и регион объясняют только Δ к log-odds готовой модели. Без этой постановки ранние эксперименты забирали сигнал, который бустинг уже умеет.
